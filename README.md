# 🗺️ Visionary Web Forge — Local Leads Map

**Lead-generation tool for web designers: find local businesses that don't have a website yet, plot them on a map and track every contact through a sales pipeline.**

---

## ✨ Features

- 📍 **Interactive map** of local businesses powered by the **Google Maps Places API**
- 🏷️ **Filter by business type** — restaurants, cafés, bakeries, clothing and shoe stores, beauty salons, gyms, real-estate agencies and more, each with its own color
- 🌐 **Website detection** — instantly spot businesses with no website (the best prospects)
- 🚦 **Business status** — open, temporarily closed or permanently closed
- 📋 **Lead pipeline** — track each prospect: *to contact → appointment → quote sent → in progress → client won* (plus rejected / not interested)
- 💾 **Zero backend** — everything runs in a single HTML file; lead data is stored locally in the browser

## 🚀 Getting started

1. Create a Google Cloud API key with **Maps JavaScript API** and **Places API** enabled (restrict it to your domain).
2. Open `index.html` and insert your key in the Google Maps script URL (`...maps/api/js?key=YOUR_KEY&libraries=places`).
3. Open the file in the browser, choose an area and the business categories to scan.
